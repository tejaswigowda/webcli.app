webCLI

A family of browser tools that take a URL or a file and return an artifact, with your content never leaving your device and no account; the paper explains the architecture.

The contract

  • URL in, artifact out.
  • GET-only. Every request a tool makes is a GET with no body.
  • Zero-egress. Your content is never sent anywhere.
  • No account, no token, no upload.

Zero-egress is about your content. A tool may still fetch static code, model weights or the input URLs you name, by GET; each card lists exactly what under fetches. An artifact is meant to be the same bytes for the same inputs; that is verified for one tool so far, and each card says.

The agent surface

Not every tool has it yet; each card says whether it does, and agent in tools.json lists which.

  • run= in the URL query (or #fragment) starts the op as soon as the page loads.
  • window.__webcli_result holds the result: { ok, op, artifact, error, meta }.
  • [data-webcli-status] on <body> is the state: idle | loading | running | done | error.
  • Stable data-testid hooks for the controls, listed on each tool's card.
// wait for the op to finish, then read the handle
await page.waitForSelector('body[data-webcli-status=done], body[data-webcli-status=error]');
const result = await page.evaluate(() => window.__webcli_result);

A worked example

For agents and scripts

The tool list on this page is rendered from one file. Fetch the same file directly:

curl -s https://webcli.app/tools.json
curl -s https://webcli.app/tools.json | jq -r '.tools[] | select(.agent) | .origin'

The file carries "schema": 2; a breaking change bumps that number. Every entry in tools is live: origin resolves over HTTPS and source is a public repository, or null with a source_status saying why. Every tool declares its group, kind, egress (whether your content leaves the device), fetches (what it GETs on first use) and deterministic. agent: true means it implements run= and the result handle; params and result describe them. Only the invariants live in the top-level contract.

Privacy and licences

These tools process what you give them on your device: they do not upload it, need no account and set no tracking identifiers. Each tool's egress and fetches say exactly what it contacts. This page makes no request to any origin but its own, and a Content-Security-Policy enforces that.
